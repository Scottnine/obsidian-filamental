# 3D Filamental Graph for Obsidian

See your vault in 3D. Every note is a node, every wikilink a connection, and physics settles them into the shape your links make.

3D Filamental Graph is free, with no account, and stays free. It comes from the team behind [Filamental](https://filamental.space), the desktop companion app that opens this same vault folder.

---

## What it does

- **Your whole vault in 3D.** Each note is a node and each wikilink a connector. The notes with the most links draw larger.
- **Physics.** Linked notes pull together, the rest spread apart, and the graph settles on its own. **Dark Energy** shakes it loose for a fresh layout and **Spin** turns it slowly.
- **Click a node** to open the note. **Drag a node** to place it, and the layout is there next time.
- **Live.** Add a link and the graph shows it straight away, without moving what you've arranged.
- **A sidebar panel** shows how many links the open note has, with a button for the graph and one for Filamental.

The plugin never changes your notes. It reads them, and keeps its layout in its own settings.

## Getting around

- **Left-drag** to orbit
- **Right-drag**, **scroll** or the **arrow keys** to pan
- **Ctrl + scroll**, or pinch on a trackpad, to zoom

Open the graph from the Filamental icon in the ribbon, or run **Open 3D Filamental Graph** from the command palette.

## Filamental, the companion app

Obsidian is where knowledge settles. Filamental is for the part still taking shape: two tools on one folder, the way a photographer takes one picture through two editors.

Filamental opens this same vault folder as a project. There you classify notes, name and direct the connections between them, and arrange the whole thing in 3D or 2D. When the work has settled it goes back to plain Markdown with its structure in the front matter, and this plugin still draws those connections.

Windows, macOS and Linux. No account, no card. **[filamental.space](https://filamental.space)**

## Settings

| Setting | Default | Description |
|---|---|---|
| Auto-launch 3D graph | Off | Opens the graph when Obsidian starts |

## Requirements

- Obsidian 1.7.2 or later, on the desktop
- A vault of up to 1,500 notes draws in full; a larger one draws its first 1,500
